# مزرعة الأرانب — برنامج إدارة مزرعة أرانب

تطبيق ويب عربي (RTL) شغال على الموبايل والكمبيوتر، بيفتح من غير إنترنت بعد أول مرة، وبيحفظ البيانات على الجهاز مع إمكانية مزامنة بين الأجهزة.

**الرابط:** https://ah77799908-star.github.io/rabbit-farm-pro/

## بيغطي إيه

| الجزء | التفاصيل |
|---|---|
| الإناث | رقم، سلالة، تاريخ ميلاد، قفص، الأب والأم، ملاحظات، صفحة كاملة لكل أنثى بتاريخها |
| الذكور | وزن متكرر، تزاوجات، نسبة نجاح، عدد صغار، إخراج من الخدمة |
| التزاوج | تسجيل بالتزاوج، تاريخ ولادة متوقع، جس حمل، **منع التزاوج بين الأقارب** (إخوة / أصل وفرع) |
| الولادات | أحياء ونافق، ملاحظات، فطام متوقع |
| الفطام والدفعات | عدد، أوزان متكررة، زيادة يومية بالجرام، نافق، بيع من الدفعة، علم «جاهز للبيع» عند الوزن المستهدف |
| الصحة | حقن وجرعات جاية، أدوية بجدول أسبوعي، برنامج تحصين بالأعمار، سجل النافق |
| العلف | أنواع علف بسعر الكيلو والمخزون، استهلاك يومي، تنبيه لما المخزون يقل، تكلفة العلف |
| الفلوس | مبيعات (وزن × سعر الكيلو)، مصروفات بالتصنيف، عملاء وفلوس آجلة ودفعات، تقرير شهري وصافي ربح |
| الأقفاص | سعة كل قفص ونسبة الإشغال |
| التقارير | نسبة الإخصاب، متوسط البطن، نفوق قبل الفطام، ترتيب الإناث بالإنتاج، سعر الكيلو، تكلفة العلف لكل كيلو |
| الأمان | نسخة احتياطية تصدير/استرجاع، نسخة تلقائية قبل أي استرجاع، تراجع عن الحذف، تصدير CSV |

## التقنية ولية اختيارها

- **HTML + CSS + JavaScript عادي، بدون أي مكتبة أو build step.** التطبيق بيتفتح فورًا من GitHub Pages، وبيشتغل أوفلاين من غير مشاكل نسخ وبناء، وأي حد يقدر يقرا الكود ويعدّله.
- **الملفات مقسومة بمسؤولية واضحة:**
  - `core.js` — كل الحسابات والمنطق (تواريخ، حالة الأنثى، التنبيهات، النسب، الفلوس، التقارير). مفيش فيه أي كود واجهة، وده اللي بيخليه قابل للاختبار لوحده.
  - `store.js` — البيانات، الحفظ في `localStorage`، التراجع، النسخ التلقائية، المزامنة.
  - `ui.js` — الغلاف والرئيسية وتبويب الأرانب وصفحات الحيوان.
  - `ui-forms.js` — كل نماذج التسجيل والحفظ والحذف.
  - `ui-tabs.js` — السجل، الصحة، الفلوس، المزيد.
  - `app.js` — التشغيل، زر التسجيل السريع، التصدير والاستيراد و CSV.
- **البيانات على الجهاز** (`localStorage`) عشان تشتغل من غير نت، و**المزامنة اختيارية** بكود من اختيار المستخدم.
- **Service Worker** بيخزن الملفات، فالتطبيق بيفتح أوفلاين ويتثبت على الشاشة الرئيسية.

## التشغيل محليًا

```bash
python3 -m http.server 8080
# افتح http://localhost:8080
```

## الاختبارات

```bash
node --test tests/core.test.js          # منطق الحسابات (بدون أي مكتبات)
npm i jsdom && node --test tests/ui.test.js   # تدفقات الواجهة
```

- `tests/core.test.js`: 13 اختبار لتواريخ وحمل وفطام وتنبيهات ونسب وفلوس وتقارير.
- `tests/ui.test.js`: 13 اختبار تدفقات كاملة في DOM حقيقي (إضافة إناث/ذكور، تزاوج، منع الأقارب، ولادة، فطام، وزن، بيع، مصروف، عميل آجل، حذف وتراجع، نسخة احتياطية، إعدادات).

## حدود معروفة

- البيانات محلية لكل جهاز؛ المزامنة بكود، ومفيش حساب مستخدم ولا صلاحيات متعددة.
- المزامنة آخر تعديل بيكسب (last-write-wins)، مش دمج سطر بسطر.
- مفيش إشعارات في الخلفية لما التطبيق مقفول؛ التنبيهات بتظهر لما تفتح التطبيق.
- الأرقام الافتراضية (31 يوم حمل، 35 يوم فطام...) تقديرات شائعة وبتتعدل من الإعدادات.
